# 📚 나의 공부습관 대시보드 (Study Habit Dashboard)

Streamlit과 Pandas를 활용하여 학생들의 공부 시간과 성적 데이터를 시각화하는 간단한 웹 애플리케이션입니다.

---

## ✨ 주요 기능
- **전체 요약 지표**: 총 학생 수, 평균 점수, 평균 공부 시간을 한눈에 확인
- **데이터 필터링**: 슬라이더를 통해 원하는 '최소 공부시간' 이상의 학생들만 골라보기 (`0.0 ~ 4.5시간`)
- **데이터 표 제공**: 조건에 맞는 학생들의 상세 데이터를 표(`st.dataframe`)로 제공
- **데이터 시각화**: 
  - 공부시간에 따른 점수 산점도 (`st.scatter_chart`)
  - 학생별 점수 막대그래프 (`st.bar_chart`)

---
